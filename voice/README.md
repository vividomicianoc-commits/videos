# VOICE CORPUS

Memória viva da voz de Vitória (`03_VITORIA_VOICE.md` #51–53). Alimenta o VITÓRIA_FIT do
script-writer e o log de aprendizado.

- **`approved/`** — conteúdos que Vitória aprovou fortemente. Nome do arquivo sugerido:
  `<canal>-<tema>-<data>.md` (canais: reel, tiktok, story, linkedin, faith, founder, personal, brand, ugc).
- **`rejected/`** — exemplos rejeitados, cada um com uma linha `WHY_REJECTED:` usando um dos
  códigos: `TOO_FORMAL · TOO_COACH · TOO_AI · TOO_CORPORATE · TOO_LONG · TOO_GENERIC · NOT_MY_WORDS`.

Quanto mais exemplos reais aqui, menos o sistema soa como IA.
