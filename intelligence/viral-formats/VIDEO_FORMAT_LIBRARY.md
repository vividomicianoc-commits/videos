# VIDEO FORMAT LIBRARY

Biblioteca central de formatos de vídeo. Objetivo: transformar cada formato em **engenharia
executável**, não uma lista de nomes. Cada formato individual vira um registro em `viral_formats`
(Format DNA) + um arquivo `VF-xxxx.md`/`VOF-xxxx.md` quando detalhado.

> **Formato ≠ assunto (#2).** Formato é **como uma ideia é embalada para prender, reter e converter
> atenção**. O mesmo tema (ex.: erro na obra da Joyeat) vira Palestrinha, Lo-fi, Cine, Narrado,
> Conflito Situacional ou The Office — a escolha é estratégica.
> **Princípio final:** COPY THE ENGINEERING · KEEP THE IDENTITY · LEARN FROM THE DATA · BUILD
> ORIGINAL FORMATS OVER TIME. Biblioteca inicial, **não** definitiva (#3) — Creator Intelligence adiciona.

## Fontes & IDs (#4/#5)
`KNOWN · CREATOR_INTEL · VIRAL_CLUSTER · REFERENCE · INTERNAL_TEST · VITÓRIA_ORIGINAL`.
IDs: **FMT-xxx** (base) · **VF-xxxx** (validado externo) · **VOF-xxxx** (original de Vitória).

## Format DNA (#6/#7) → tabela `viral_formats`
`name · category · source · description · primary/secondary objective · best pillars · best
platforms · ideal duration · hook style · visual hook · structure · editing DNA · delivery ·
audio · retention devices · payoff · CTA · signature compat · effort · repeatability · Vitória fit
· status`. **Status:** HYPOTHESIS → REFERENCE → TESTING → VALIDATED_EXT → VALIDATED_VITÓRIA →
STRONG → DECLINING → SATURATED → RETIRED. **Performance acumulada (#8):** test count, avg/median
views, follow/share/save rate, profile visits, effort, Content ROI.

## Formato é composição (#9/#10) — camadas separadas
Um vídeo combina: **BASE FORMAT** (estrutura) + **DELIVERY STYLE** (como é entregue) + **HOOK
ENGINE** (como começa) + **STORY ENGINE** (como progride) + **EDITING STYLE** + **AUDIO STRATEGY**
(+ SIGNATURE). O Chief of Content **compõe** combinações (Format Composition Engine) — ex.:
`Conflito Situacional + Lo-fi + Confession + (Expectation→Problem→Realization) + Fast Talking Head
+ recognizable low-volume + cut dry`.

## Mecanismos de viralização (#11/#12)
Curiosidade/efeito Aha · Contraste · Conflito/mudança · Linguagem familiar/imagem mental ·
Relevância emocional (medo, ambição, identificação, desejo, insegurança, esperança, fé,
pertencimento). Buscar também: open loop, status, specificity, surprise, confession, social proof,
relatability, nostalgia, POV, tension, mystery, challenge, transformation, humor, pattern interrupt.

## Descoberta, clustering, validação (#82–86)
`Video DNA → estrutura já existe? → se não, candidato → outros exemplos → validar cluster → criar
VF`. Não criar formato por vídeo (agrupar). Confiança maior quando: múltiplos creators + outliers +
transferível + não depende de uma personalidade + não saturado. Stage EMERGING→DECLINING;
GROWING + alto Vitória Fit = testar rápido (não esperar saturação).

## Transferibilidade & referência (#87–92) → `transferability` (JSON)
Avaliar 0–10 por: FOUNDER · BUSINESS · BRAND · MARKET · FAITH · LIFESTYLE · PERSONAL · JOY · UGC.
Cada formato guarda `reference_creators/videos/DNA`. Ao receber vídeo de referência → **FULL Video
DNA** (`intelligence/video-dna/REF-xxxx.md`). Replicação = **MUST PRESERVE** (o que faz funcionar:
hook <1s, conflito antes do contexto, mudança visual no 4s, payoff no final) vs **CAN ADAPT**
(cenário, história, palavras, produto, B-roll). Nunca copiar roteiro/história/frase/identidade.

## Áudio como componente (#93/#94, #127) — guardrail de valores
Registrar função da música (nostalgia, crescendo, beat, reveal, irony, recognition). Mesmo em
formato viral, **validar letra/valores/licença** (ver `brand/10` + `audio_library`); letra
incompatível → áudio alternativo com **função equivalente**.

## Matching & aprendizado (#99–107, #118–121)
Aprender (com dados) as combinações Format×Pillar, Format×Platform, Format×Audio, Format×Signature.
Format Performance Autopsy em outliers (não creditar só o formato). Testar formato >1 vez
(2–5 conteúdos variando tema, preservando engenharia). Format Failure Diagnosis:
FORMAT/EXECUTION/TOPIC/HOOK/AUDIENCE/TIMING/UNKNOWN. Format ROI (value ÷ effort). **Content/Format
Rescue:** tese boa que falhou pode funcionar com outra embalagem (Palestrinha → Lo-fi Storytelling).
Format fatigue: variar embalagem — **recognition, não repetition** (#119).

## Core vs Experimental & VOF (#108–112)
**Core Formats:** representam Vitória, funcionam, repetíveis, bom ROI. Manter espaço para
**Experimental**. **VOF** quando um formato nasce/transforma no sistema + uso consistente +
reconhecido + identidade + performa + repetível. Outros copiarem = sinal de influência cultural.

## Import de outras categorias (#122–126)
beauty → Joy Power (ritual, GRWM, before/after, placement) · fashion → personal brand (aspirational
storytelling, identity, lifestyle integration) · business → founder (opinion hooks, authority,
specificity) · entertainment → retention (pacing, suspense, pattern interrupt, payoff — não copiar humor/identidade).

## Recomendação de formato pelo Chief of Content (#113–117, #131/#132)
Output: `TOPIC · PILLAR · PRIMARY OBJECTIVE · BASE FORMAT · FORMAT_ID · HOOK ENGINE · VISUAL HOOK ·
STORY ENGINE · DELIVERY · EDIT STYLE · AUDIO STRATEGY · REFERENCE VIDEO · SIGNATURE · EXPECTED
EFFORT · WHY THIS FORMAT`. Sempre com **evidência** (não por gosto) e **sem falsa precisão**
(HIGH/MEDIUM/EXPERIMENTAL potential, nunca *"vai viralizar"*). Recomendar respeitando **tempo
disponível** (5min/20min/2h) e **ambiente** (walking/car/office/construction/gym/event/home).

## Templates por formato (#133–137)
Cada formato pode ter: Shoot List template, Edit template, Cover/Thumbnail logic, Caption logic,
CTA logic — alimentando Daily Shoot List e (futuro) edição automática. Todos respeitam Brand
Guardrails (#138): Conflito Situacional não fabrica conflito; Experimento Social exige
consentimento; Reaction respeita copyright.

## Same-day / evergreen / high-effort (#128–130)
- **Same-day:** Lo-fi, Palestrinha, Reaction+Analysis, Comment Response, Story, Simple Narrated.
- **Evergreen:** Founder Diary, Palestrinha, Narrado, Storytelling, Comparison.
- **High-effort (situacional):** Cine, Micro-documentary, Complex Storytelling Visual.

## Cadência de revisão (#139–143)
Semanal: BEST/WORST/NEW/RETEST format. Mensal: promover/rebaixar/atualizar/retirar/adicionar.
Meta de granularidade (#142): não *"lo-fi funciona"* — mas *"lo-fi + personal realization funciona
melhor em Faith"* / *"Conflito Situacional + walking delivery funciona melhor em Founder"* — só com dados.
