# VITÓRIA OS

Sistema operacional de inteligência, conteúdo e marca pessoal.
**Claude Code é o cérebro.** As ferramentas conectadas são os braços, olhos e mãos.

> Princípio fundador: **MINHA VIDA GERA CONTEÚDO** — o sistema transforma o que já
> está sendo vivido em conteúdo, distribuição e autoridade. Não o contrário.

## O estado atual em uma frase

Você já tem um ambiente **excepcionalmente rico**: Instagram e TikTok analytics
**autenticados e vivos agora**, mais Google (Calendar/Drive/Gmail), Notion, Canva,
Adobe, Gamma, Figma, Supabase e Descript conectados. A maior parte do VITÓRIA OS
pode ser construída via conectores existentes — **pouco código próprio será necessário**.

Leia nesta ordem: `00_DISCOVERY_AUDIT` → `CONNECTOR_MAP` → `GAP_ANALYSIS` →
`RECOMMENDED_STACK` → `SETUP_CHECKLIST_VITORIA` → `QUICK_WINS`.

## O loop que este sistema roda

```
OBSERVE → ANALYZE → DECIDE → CREATE → PUBLISH → MEASURE → LEARN → UPDATE MEMORY → (repeat)
```

Cada volta deixa o sistema mais inteligente que qualquer social media genérico —
porque ele conhece a SUA história, marcas, audiência, dados, erros e objetivos.
